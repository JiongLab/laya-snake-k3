# v0.1.0 — K3 复现包（预发布）

交付中文复现指南、固定模型下载清单、K3 适配源码、Debian 应用包、16 个版本锁定的 Python wheels 以及通用/硬件测试。

上游通用优化已提交：[laya-mlx #4](https://github.com/mizorewww/laya-mlx/pull/4)。未声明已合并。

## 验证状态

- 公开 v0.1.0 源码、wheels、安装包重新下载并校验；6 个模型文件从固定公开地址新下载，经电脑中转后导入 K3 独立 venv，依赖和哈希检查通过。
- 43 项测试全部通过、无跳过，包含 121 输入精度/线程稳定性、快速与完整指标模式各 60 步，以及打包测试。
- 实际安装入口的终端暂停、恢复、重开、退出及终端状态恢复通过；首帧 24.36 秒。
- 实际安装入口长蛇 1,200 步通过，填满棋盘一次，零死亡、零保护介入，排除首步平均 110.29 ms/步。
- 测试环境为 Bianbu 4.0.7 + 锁定系统库。K3 直连 GitHub/Hugging Face 超时，验证的是文档支持的电脑中转/离线导入路径；未重刷系统，也未重复执行同版本 sudo 安装。已安装程序与新下载包逐文件一致。
- 此次同步验收结果，保留 prerelease 标记和原资产；完整方法与结果见 [验收记录](VALIDATION.md)。

## 资产

- `laya-snake-k3_0.1.0_riscv64.deb`：应用、文档、运行时 wheels；不含模型和系统库。
- `laya-snake-k3-runtime-wheels-0.1.0.tar.gz`：源码安装用的相同 wheels。
- `laya-snake-k3-source-0.1.0.tar.gz`：本发布对应源码、文档和测试。
- `SHA256SUMS`：以上资产校验值。

目标环境为文档中的 Bianbu 4.0.5 K3，以及已补测的 Bianbu 4.0.7 + 相同锁定系统库，不适用于普通 x86/ARM Linux。建议在独立用户数据目录试用，不覆盖现有可用部署。

发布资产保留构建时快照，不覆盖重传；最新验收进展以仓库 main 分支的 `docs/VALIDATION.md` 和本发布说明为准。
